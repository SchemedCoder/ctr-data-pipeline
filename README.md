

# CTR Data Pipeline 

## Overview
Built a data pipeline to calculate Click-Through rate from ad event logs.Built a data pipeline to process ad events and compute CTR metrics, enabling performance analysis of digital campaigns.

---

## Architecture
CSV → ETL (Python) → Aggregation → SQLite → SQL Analysis

---

## Features
- Impression & click tracking  
- CTR calculation  
- Data quality handling  
- SQL-based analytics  

---

## Tech Stack
- Python (Pandas)
- SQL (SQLite)
- Airflow (optional)

---

## Business Impact
- Identify high-performing ads  
- Optimize ad campaigns  
- Monitor user engagement
